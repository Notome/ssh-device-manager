# 🚀 SSH Manager

Полноценное веб-приложение для управления сетевыми устройствами (роутеры, свитчи, серверы) через SSH.

![SSH Manager](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Flask](https://img.shields.io/badge/Flask-3.0.0-green.svg)
![License](https://img.shields.io/badge/License-MIT-yellow.svg)

## 📋 Описание

SSH Manager - это современное веб-приложение с темной темой для централизованного управления сетевыми устройствами. Позволяет выполнять SSH команды, отслеживать статус устройств и вести историю операций.

## ✨ Основные возможности

### 🎯 Управление устройствами
- ✅ Добавление, редактирование и удаление устройств
- ✅ Хранение учетных данных SSH (логин/пароль)
- ✅ Категоризация по типам (Router, Switch, Server, Firewall)
- ✅ Поиск по имени и IP-адресу
- ✅ Фильтрация по типу и статусу

### 🔌 SSH подключения
- ✅ Выполнение команд на удаленных устройствах
- ✅ Вывод результатов в стиле терминала
- ✅ Обработка ошибок подключения
- ✅ Поддержка различных типов устройств

### 📊 Мониторинг
- ✅ Автоматическая проверка доступности через ICMP ping
- ✅ Статусы устройств (Online/Offline)
- ✅ Статистика на дашборде
- ✅ Визуальные индикаторы состояния

### 📝 История команд
- ✅ Логирование всех выполненных команд
- ✅ Просмотр истории для каждого устройства
- ✅ Общая история всех операций
- ✅ Отметки об успешности выполнения

### 🎨 Современный UI/UX
- ✅ Темная тема в стиле современных приложений
- ✅ Боковое меню навигации
- ✅ Карточки статистики
- ✅ Анимации и hover-эффекты
- ✅ Адаптивный дизайн
- ✅ Flash-уведомления

## 🛠️ Технологии

- **Backend:** Python 3.8+ / Flask 3.0
- **База данных:** SQLite3
- **SSH:** Paramiko
- **Frontend:** HTML5 + CSS3

## 📖 Использование

### Добавление устройства
1. Нажмите "Добавить устройство" в боковом меню
2. Заполните форму:
   - Название устройства
   - IP-адрес
   - Тип (Router/Switch/Server)
   - Логин и пароль SSH
3. Нажмите "Добавить устройство"

### Выполнение SSH команд
1. На дашборде нажмите "Управлять" у нужного устройства
2. Введите команду (например: `show version`, `ls`, `ip addr`)
3. Нажмите "Выполнить"
4. Результат отобразится в терминале

### Проверка статусов
1. На дашборде нажмите "Обновить статусы"
2. Приложение проверит доступность всех устройств через ping
3. Статусы обновятся автоматически

### Поиск и фильтрация
- Используйте строку поиска для поиска по имени или IP
- Выберите тип устройства из выпадающего списка
- Фильтруйте по статусу (Online/Offline)

## 🔒 Безопасность

⚠️ **ВАЖНО:** Это тестовая версия приложения!

- Пароли хранятся в открытом виде в SQLite
- Нет шифрования данных
- Нет аутентификации пользователей
- Не используйте в продакшене без доработки!

### Для продакшена рекомендуется:
- Шифрование паролей (bcrypt, cryptography)
- Аутентификация пользователей (Flask-Login)
- HTTPS соединение
- Ограничение доступа к API
- Логирование действий пользователей

## 📝 API Endpoints

- `GET /` - Главная страница (дашборд)
- `GET/POST /add` - Добавление устройства
- `GET/POST /edit/<id>` - Редактирование устройства
- `GET /delete/<id>` - Удаление устройства
- `GET /refresh_status` - Обновление статусов
- `GET/POST /device/<id>` - Управление устройством
- `GET /history` - История команд
- `GET /api/device/<id>/status` - API статуса устройства (JSON)
- `GET /scan_network` - Сканирование сети (заглушка)

## 🐛 Известные ограничения

- Ping работает только для доступных в сети устройств
- SSH требует установленного paramiko
- Нет поддержки SSH ключей (только пароли)
- Нет многопользовательского режима
- История команд не ограничена (может расти)

## 📚 Зависимости

- **Paramiko 3.4.0** - SSH клиент для Python
